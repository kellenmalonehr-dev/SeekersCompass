; Grace Items. Each [id] starts an item; save files refer to items by that id, so don't rename one
; that characters already own. Graces are listed by id, with names, in graces.txt.
;
; Items in one track upgrade in place: a character uses the highest tier it owns, and the Camp menu
; shows one line per track. Discovering a grace in "found" gives the item, including graces
; discovered before the mod was installed.
;
; Seats set how long the buff lasts. Keepsakes set what it raises: a point for every
; kills_per_point kills since your last sit, up to max. A Stamina point is 1% of max stamina.
; The camp menu numbers items by their order here (up to 64), so rebuild the menu after changes.
; Seats lie on the ground under the sitting player. "right" and "forward" (meters, as the sitting
; player faces) shift a model whose middle isn't where it should be; "turn" (degrees) turns it.
; (A seat with "lift = <height>" raises the player onto it, but they keep the ground-sitting pose,
; so no seat uses it.)
; Written from ITEMS-DRAFT.md.
